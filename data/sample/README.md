# Sample bundle (synthetic)

This is a small bundle, committed to the repo, that is used when `SAMPLE_MODE=true` (spec P1). It contains:

- about 600 crimes, 3 series and 40 tips;
- `model_fixtures/`, recorded from **live** Nightshift calls.

It is generated by `python -m data.generator` and never edited by hand. Every row carries `synthetic: true`.
